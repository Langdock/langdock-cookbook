# Agent API Recipes

Recipes for the [Langdock Agent API](https://docs.langdock.com/en/developer/agents-api/agents-overview)
— chat completions, attachments, and embedding an agent on your own site.

| Recipe | What it shows |
|---|---|
| [`embed-widget/`](embed-widget/) | Iframe / chat bubble in front of an existing agent, including pasted screenshots and file attachments. |
